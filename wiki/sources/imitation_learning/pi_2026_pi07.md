# π0.7：多様なpromptで操る汎用VLAとcompositional generalization

## 論文の位置づけ

Physical Intelligence, *π0.7: a Steerable Generalist Robotic Foundation Model with Emergent Capabilities*（2026）。保存PDFは25ページ。単一の汎用VLAに、詳細な言語指示、subgoal画像、episode metadataを条件として与え、専門方策に近い器用さと、新しい組合せのタスク・ロボットへの転移を目指す。[Abstract・§I・V–VI](../../../raw/papers/pi_2026_pi07.pdf)

## 何を条件として行動を生成するか

| 条件 | 役割 |
| --- | --- |
| Task / subtask instruction | 全体目標と直近の操作。subtaskは学習済みhigh-level policyまたは人の言語coachingが指定 |
| Subgoal images | 現観測とsubtaskを条件に、別のworld modelが生成する複数視点の目標画像 |
| Episode metadata | episode長、品質1–5、局所的ミスの有無で、異なる品質・速度のbehaviorを区別 |
| Control mode | joint / end-effectorの切替 |

subgoalのworld modelはBAGEL由来の14Bモデルで、動画・human egocentric dataなども使って学習する。行動を候補ごとにrolloutしてvalueで探索する方式としては説明されていない。[§V・Fig.3・Appendix C](../../../raw/papers/pi_2026_pi07.pdf)

学習時はprompt要素をdropoutする。subgoal画像を付けるのはbatchの25%で、実際の未来画像と生成画像を使う。実行時は品質5・ミスなしを指定し、速度はタスクのepisode長の15th percentileを設定する。subgoalはsubtask変更時または4秒経過時に非同期更新する。[§V-E・VI-C・VII・Algorithm 1](../../../raw/papers/pi_2026_pi07.pdf)

## モデル・データ・実行

VLMと860Mのflow matching action expertを使い、視覚履歴とproprioception、subgoal画像を入力する。最大4視点、各視点最大6枚の履歴、最大3視点のsubgoalに対応。50-stepのaction chunkを5 denoising stepsで生成し、そのうち15または25 stepsを実行する。RTCで推論遅延に対応し、UR5eは20 Hz、他の評価ロボットは50 Hzで制御する。[§VI-B–C・VII–VIII](../../../raw/papers/pi_2026_pi07.pdf)

デモに加え、過去方策の自律評価rollout、人の介入、open-source robot data、human video、Webの非ロボットデータを使う。π*0.6がRLで集めたデータも含み、専門方策のbehaviorを汎用モデルへ蒸留する。汎化評価の対象タスクの自律データは学習から除くと明記する。[§VI-A・脚注1](../../../raw/papers/pi_2026_pi07.pdf)

## 評価を分けて読む

### 既知タスクでの専門方策との比較

洗濯・espresso・箱組立では、task-specificなRL specialist π*0.6と比較し、単一のπ0.7が競合する性能を示す。多様な洗濯と箱組立はthroughputで上回る。これらは学習データに含まれるタスクであり、「一度も見ていないタスク」の結果ではない。Fig.6上段は専門方策を基準に正規化したthroughputと成功率、下段の他タスクはtask progressで、縦軸が異なる。[§IX-A・Fig.6](../../../raw/papers/pi_2026_pi07.pdf)

metadataを除く／自律評価データを除くablationでは性能が低下する。過去の評価rolloutを学習に含めたモデルなので、専門方策との比較を「その方策の経験を全く使わない独立な比較」とは読まない。[§VI-A・IX-A・Fig.7](../../../raw/papers/pi_2026_pi07.pdf)

### 言語指示・ロボット間転移・未知タスク

- 詳細な指示、物体・場所・操作方法への追従を評価する。
- 新たなtask–robotの組合せに対するcross-embodiment transferを評価する。UR5eのshirt foldingでは、専門の人間operatorがtask progress 90.9%・成功率80.6%、π0.7が85.6%・80%。進捗率と成功率は別指標。
- 短い未知タスクは直接promptで、長い未知タスクは人が段階的な言語coachingを行って評価する。長い未知タスクが全体指示だけで自動完遂できたという結果ではない。
- coaching episodeからhigh-level language policyを追加学習すると、低レベルの新規teleoperationデータなしで自律化できる。これはcoachingや追加学習が不要という意味ではない。

出典：[§IX-B–D・Figs.8–17・Appendix F](../../../raw/papers/pi_2026_pi07.pdf)。

### データ量と多様性のablation

洗濯データの品質・速度上位30%・50%・80%・全量を用いる8モデルの比較では、metadata付きは低品質データを加えても改善するが、metadataなしは悪化し得る。多様性の高い20%の除去は、同量をランダム除去するより未知短期タスク性能を悪化させる。全種類のデータ・任意のノイズを無制限に加えて良いと証明したものではない。[§IX-E・Fig.18](../../../raw/papers/pi_2026_pi07.pdf)

## 限界

著者は既知タスクがしばしば90%以上の成功率である一方、未知タスク／未知task–robotの組合せは60–80%程度と述べるが、全タスク共通の集計値ではない。大規模混合データでは関連するskillが別の場所に含まれるため、seen / unseenを完全に切り分けることは難しい。compositional generalizationは、既存skillの再結合という解釈を含む。[§X](../../../raw/papers/pi_2026_pi07.pdf)
