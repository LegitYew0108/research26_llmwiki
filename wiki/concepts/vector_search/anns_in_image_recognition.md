# 画像認識におけるANNSの役割

## どの処理で使うか

ANNS（Approximate Nearest Neighbor Search）は、画像や画像の一部分を表す特徴の中から、クエリと距離の近いものを高速に探す処理に使える。HNSW原論文は大規模データベースでの画像特徴の照合を近傍検索の用途として挙げている。以下の流れは、この用途を理解するための概念的な説明であり、特定の製品の実装を述べるものではない。[出典：§1](../../../raw/papers/1603.09320v4.pdf#page=1)

```text
登録画像 → 特徴抽出 → 特徴ベクトルを検索用indexへ登録
入力画像 → 同じ方法で特徴抽出 → ANNS → 近い特徴のID・距離
                                              ↓
                                   対応する画像やラベルを利用
```

特徴抽出と近傍検索は別の役割である。HNSWは与えられた距離で近い要素を探す検索構造であり、画像から意味のある特徴を学ぶ方法そのものではない。原論文ではSIFT、画像から抽出したMPEG-7特徴、deep image descriptorなどを検索対象として評価している。[出典：§1、§5.3 Table 1](../../../raw/papers/1603.09320v4.pdf)

## 用途を理解するための例

以下は近傍検索の役割を説明する例であり、HNSW論文が各用途の認識精度を実証したという意味ではない。原論文が示す用途は画像特徴の照合とnon-parametric machine learningであり、評価の中心は検索性能である。[出典：§1、§5](../../../raw/papers/1603.09320v4.pdf)

| 使う場面 | 検索する対象 | 検索結果の使い方の例 |
| --- | --- | --- |
| 類似画像検索 | 画像全体を表す特徴 | 入力した商品写真と似た登録画像を表示する |
| 局所特徴の照合 | キーポイント周辺などの特徴 | 別の写真のどの部分に対応するかの候補を得る |
| 近傍に基づく分類 | ラベル付き画像の特徴 | 近い画像のラベルを使って入力のクラスを決める |

局所特徴の照合では、1枚の画像が複数の特徴ベクトルに対応する場合がある。「画像1枚を必ず1ベクトルにする」とは限らない。原論文のSIFT評価も画像特徴ベクトルの検索であり、画像認識システム全体の評価とは区別する。[出典：§1の画像特徴照合と引用[1]、§5.3 Table 1](../../../raw/papers/1603.09320v4.pdf)

## なぜ近似検索にするか

全探索は登録要素すべてとの距離を計算するため、登録数に対して計算量が線形に増える。ANNSは真の最近傍を一部取り逃すことを許して、検索の高速化を図る。HNSWはそのためのグラフベースの手法の一つである。[出典：§1、§4](../../../raw/papers/1603.09320v4.pdf)

検索recallと認識精度は同じ指標ではない。原論文のrecallは真の近傍を回収できた割合である。したがって「検索が高速・高recallである」という評価だけから、画像分類の正解率まで保証されるとは解釈できない。[出典：§1、§5](../../../raw/papers/1603.09320v4.pdf)
