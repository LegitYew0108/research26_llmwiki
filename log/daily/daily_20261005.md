# 2026-10-05 作業記録

## Review：Behavior CloningとImitation Learning

対象：[BCの理解](<../../mind/IL/BC-Behavior Cloning.md>)、[ILの理解](<../../mind/IL/IL-Imitation Learning(模倣学習).md>)。
本文は維持し、frontmatter、関連ページと一次資料のリンクを追加した。以下は修正案であり、ユーザー本文には反映していない。

### BCの修正案

1. **「完全に再現する」は強すぎる。** 修正案：「expertのデモに含まれる観測・状態と行動から、expertの行動に近い出力をする方策を教師あり学習する」。学習目的と完全再現の保証を区別する。[Osaら §2.2・3](../../raw/temp/osa_2018_imitation_learning_survey.pdf)、[DAgger §1](../../raw/temp/ross_2011_dagger.pdf)
2. **カメラ・関節角の入力は、stateよりobservationと書く方が明確。** 修正案：「時刻tの観測 $o_t$（画像・関節角など）から、その時刻に選ぶ行動 $a_t$ を予測し、デモの行動 $a_t^*$ と比較する」。状態を十分観測できる仮定なら $s_t$ でもよい。「次の行動」は $a_{t+1}$ と混同されやすいため時刻を明示するとよい。[Offline RL tutorial §2.1](../../raw/temp/levine_2020_offline_rl_tutorial.pdf)、[ACT §IV](../../raw/papers/zhao_2023_act.pdf)
3. **連続行動の損失をMSEに限定しない。** 修正案：「連続行動を直接回帰する場合、MSEは代表的な選択肢。L1 lossなども使われる」。ACT本文はL1 reconstruction lossを用いる（Algorithm 1のMSE表記との不一致は既存Wikiに注記済み）。離散行動の分類についても「クロスエントロピーがよく使われる」という例示にすると、損失が一意に決まるという誤解を避けられる。[Osaら §3](../../raw/temp/osa_2018_imitation_learning_survey.pdf)、[ACT §IV](../../raw/papers/zhao_2023_act.pdf)
4. **誤差の累積の説明は概ね正しい。** 「普通の学習」は「固定データを用いた通常の教師あり学習」に、「模倣学習では」は「学習した方策の実行時には」にすると、学習時と実行時が明確になる。未経験の状態で必ず誤るという意味ではなく、誤りやすくなるリスクとして書くとよい。道路の例は説明用の仮想例と明示すると出典の事例との混同を避けられる。[DAgger §1–2](../../raw/temp/ross_2011_dagger.pdf)

### ILの修正案

1. **「学び、」で終わる文を完成させる。** 修正案：「デモで示された観測・状態と行動の関係などを利用し、状況に応じて行動を選ぶ方策を学ぶ」。BCにはexpertの行動という教師ラベルがあるが、全状況に対する唯一の最適行動が分かるわけではない、と分けて説明すると「完全な正解データがあるというより」の曖昧さが減る。[Osaら §2.1–3](../../raw/temp/osa_2018_imitation_learning_survey.pdf)、[DAgger §2–3](../../raw/temp/ross_2011_dagger.pdf)
2. **RLの説明はonline RLに偏っている。** 修正案：「RLは、期待累積報酬を大きくする方策を学ぶ。online RLでは環境と相互作用して経験を集め、offline RLでは既存の遷移・報酬データから学ぶ」。環境が未知であることはRL全体の定義に必須ではない。「正解データはない」は「通常、expertの行動ラベルを直接の学習基準にはせず、報酬を基準にする」とすると、デモを併用するRLも扱える。[Offline RL tutorial §2.1–2.2](../../raw/temp/levine_2020_offline_rl_tutorial.pdf)、[Osaら §1・5](../../raw/temp/osa_2018_imitation_learning_survey.pdf)
3. **IRLの直接の学習対象を補足すると分類が分かりやすい。** 修正案：「BCは行動から直接方策を学び、IRLはデモから報酬・costを推定し、それに基づく方策を求める」。ILの手法をすべて同じ形式の行動予測として捉えないための補足。[Osaら §2.2・4・5.1](../../raw/temp/osa_2018_imitation_learning_survey.pdf)
